# Birthday world

Open `index.html` directly, or serve the folder (`python3 -m http.server`) / drop it on any static host (Vercel, Netlify, GitHub Pages).

Personalise at the top of `app.js` (`CONFIG`): name, sign-off, the nine hidden wishes. The letter text lives in `index.html` (`#paper`).
No build step. three.js r149 is vendored in `vendor/`.
