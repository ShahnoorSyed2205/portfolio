# Gentleman – birthday site

Static site, no build. Open `index.html` or deploy the folder to Vercel.

- `music/song.mp3` – drop your own track here. Without it, a built-in slow raga-style score plays.
- `img/cars/`, `img/armoury/` – his real photos (wiring pending).
- Edit name / sender / wishes in `CONFIG` at the top of `app.js` (name is "Mr. Khan", nickname "Pathaan").
- Debug: append `#debug` to the URL.
